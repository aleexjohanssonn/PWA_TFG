# PWA_TFG

Progressive Web Application developed as part of a Bachelor's Thesis (TFG) in Industrial Technologies Engineering at ETSEIB-UPC.

The application helps microentrepreneurs in vulnerable environments manage their 
daily operations — cash flow, inventory and sales — and calculates the hourly 
income generated by their work.
The original application provides two versions for different business profiles:

- **Manufacturing / food & fast-sales profile** (with inventory management): 
  https://aleexjohanssonn.github.io/PWA_TFG/con-stock/
- **Services profile** (no inventory management): 
  https://aleexjohanssonn.github.io/PWA_TFG/servicios/

## Batch-production version

A first research version supporting production followed by later sales is available at:

https://aleexjohanssonn.github.io/PWA_TFG/batch-production/

Its source is in `batch-production/`. The original inventory and services application files are unchanged.

This version adds production events, finished-goods stock, partial sales, FIFO allocation and controlled cancellation. It uses its own browser storage key (`pwa_tfg_batch_v1`) and does not migrate or overwrite legacy records. This is an initial research version; user evaluation is still pending. Records are saved only in the browser and are not synchronised between devices.

To preview from the repository root:

```sh
python3 -m http.server 8081 --bind 127.0.0.1
```

Then open http://127.0.0.1:8081/batch-production/ on the same computer.

Run the domain and service-worker checks with Node.js:

```sh
node --test tests/batch-core.test.cjs tests/batch-sw.test.cjs
```

This work extends Alfonso Benavides Fortuny's original PWA; the batch workflow is part of Alexander Johansson's research assignment. Developer checks are not a substitute for user evaluation. See `batch-production/README.md` for data definitions and current limits.
