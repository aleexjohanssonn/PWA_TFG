¿Cómo se calculan estos números?

La caja muestra ventas cobradas menos compras registradas. El pago por hora usa el tiempo de fabricación asignado a las ventas y su tiempo adicional de venta, después de materiales. No descuenta alquiler, transporte, impuestos ni otros gastos, y no representa todo el trabajo del período.
